# Sua Jornada · Arrematador 360

Página de onboarding do aluno do Arrematador 360.

- Endereço: https://jornada.arrematador.com
- Hospedagem: GitHub Pages (branch `main`, pasta raiz)
- Arquivo principal: `index.html` (página única, imagens embutidas)

## Domínio
No DNS de `arrematador.com`, crie um registro:

| Tipo | Nome | Valor |
|---|---|---|
| CNAME | jornada | tfalavina.github.io |

## Página de renovação

- Endereço: https://jornada.arrematador.com/renovacao/
- Arquivo: `renovacao/index.html`
- Cópia da página principal para alunos que renovaram. Não tem o passo de check-in. Os 3 primeiros passos são: Arrematador App, grupo do Guia Leilões e grupo Escala.
